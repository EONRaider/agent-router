# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and not the person,
and do not harass anyone. This applies in issues, pull requests, discussions and any other
space where the project is represented.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@EONRaider](https://github.com/EONRaider),
through GitHub. Reports are kept confidential. The maintainer may remove comments, close
threads, or block contributors who do not follow this code, as described in the Contributor
Covenant's enforcement guidelines.
